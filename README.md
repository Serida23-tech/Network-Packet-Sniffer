# Network-Packet-Sniffer
It demonstrates network traffic monitoring, protocol filtering, and basic attack detection using Python and Scapy.
The project will have four main features:
1. Live packet capture — capture packets from a network interface.
2. Protocol filtering — monitor TCP, UDP, and ICMP traffic.
3. IP and port extraction — display source and destination IP addresses and ports.
4. Security alerts — detect suspicious ARP address changes and flag possible cleartext HTTP credential submissions.
Only run packet captures on networks and devices you own or have permission to monitor.
